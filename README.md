# Customer Churn Analysis 📊

## 📌 Project Overview
Customer churn analysis helps businesses understand why customers stop using their services. This project analyzes customer data using Python to identify churn patterns, understand customer behavior, and highlight potential revenue risks.

## 🎯 Project Objectives
- Analyze customer churn and retention rates.
- Clean and explore customer data.
- Identify important customer behavior patterns.
- Calculate key business metrics.
- Visualize insights to support better business decisions.

## 🛠️ Tools & Technologies
- **Python** – Data analysis
- **Pandas** – Data cleaning and manipulation
- **NumPy** – Numerical operations
- **Matplotlib & Seaborn** – Data visualization
- **Jupyter Notebook** – Analysis and documentation

## 📂 Repository Contents
- `Customer churn.ipynb` – Notebook containing data analysis and visualizations.
- `customer_churn_data.csv` – Dataset used for the analysis.

## 🔄 Project Workflow
1. Load the customer dataset using Pandas.
2. Inspect the data structure and data types.
3. Check and handle missing values and duplicate records.
4. Perform exploratory data analysis (EDA).
5. Calculate churn, retention, and other business metrics.
6. Visualize patterns and summarize key findings.

## 📊 Key Findings
- **Total customer records analyzed:** 21
- **Churn rate:** 28.57%
- **Retention rate:** 71.43%
- **Revenue at risk:** ₹73.94K

*These results are based on the current notebook analysis.*

## 💡 Business Insights
- Understanding churn helps businesses identify customers who may need additional support.
- Tracking retention helps measure customer loyalty.
- Revenue-at-risk analysis can help prioritize customer retention efforts.
- Data visualization makes customer behavior patterns easier to understand.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

3. Open the notebook:

   ```bash
   jupyter notebook
   ```

4. Run `Customer churn.ipynb` cell by cell.
